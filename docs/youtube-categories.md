# Video categories

The local catalogue includes 15 ordinary YouTube upload categories and 17 historical/API movie and TV categories. Legacy categories are also assignable within Sprout, independently of YouTube restrictions; this is a pinned catalogue rather than a live region-dependent API response. Category 34 is labelled “Comedy (Movies)” to distinguish it from category 23. Older Sprout categories are normalized at display and edit boundaries so stored uploads remain searchable.

Protocol and meanings: https://developers.google.com/youtube/v3/docs/videoCategories
Historical IDs and uploader taxonomy snapshot: https://gist.github.com/dgp/1b24bf2961521bd75d6c
Studio navigation and editing references: https://support.google.com/youtube/answer/7548152 and https://support.google.com/youtube/answer/57404

No YouTube account, Google API key or remote asset request is used. YouTube monetisation, Content ID, live streaming and audience profiling are not implemented by this layout.
