# 2020 layout references
Original Sprout CSS in app/legacy-2020.css, informed by a YouTube Music clone created in 2020:
- https://github.com/gersongams/YT-music-clone/blob/master/src/style/globalStyle.tsx
- https://github.com/gersongams/YT-music-clone/blob/master/src/containers/Header.tsx
The reference uses CSS-in-JS rather than a downloadable .css file. No licence was present, so its implementation was not copied or bundled. Sprout uses original CSS, locally served assets and system fonts.

YouTube video palette reference: https://github.com/manikandanraji/youtubeclone-frontend/blob/master/src/styles/theme.js (MIT; see video site attribution).
These are community projects, not official Google CSS. 2020 creation dates do not imply every current file is an exact 2020 snapshot.
